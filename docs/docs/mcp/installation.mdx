# MCP Server

QuickCrawl MCP server provides AI agents with web scraping capabilities. Works with every major AI agent.

## Quick Install (all agents)

```bash
npx agent-install@latest mcp add @mabudalam/quickcrawl-mcp -g
```

## Claude Code

Anthropic's CLI agent:

```bash
npx agent-install@latest mcp add @mabudalam/quickcrawl-mcp -g -a claude-code
```
