# QuickCrawl Skill

Install the QuickCrawl Skill to teach any AI coding agent how to use QuickCrawl automatically.

## Install Skill

```bash
npx skills add MabudAlam/QuickCrawl
```

This discovers both skills (`quickcrawl-cli` and `quickcrawl-mcp`) and installs them to your agent. After installation, the agent knows how to scrape, crawl, map, and search without any manual instructions.
